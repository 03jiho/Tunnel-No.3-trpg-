# 제3갱

1980년대 폐광촌을 배경으로 한 한국어 솔로 TRPG 텍스트 어드벤처입니다. 브라우저에서 바로 실행되며, 별도 설치나 빌드 과정이 없습니다.

🔗 **바로 플레이하기**: https://03jiho.github.io/Tunnel-No.3-trpg-/

## 배경

삼 년 전 붕괴 사고로 봉쇄된 금광 '제3갱'이 재개발로 내일이면 완전히 물에 잠긴다는 소문이 돈다. 빚에 몰린 외지인인 플레이어는 마지막 기회를 노리고 몰래 갱도에 잠입한다. 안에는 사고 때 죽은 광부들의 소문과, 누구도 확인하지 못한 진짜 금맥이 있다는 이야기가 함께 떠돈다.

## 놀이법

- **과거 선택**: 시작 전 배경 4종 중 하나를 골라 고유한 능력을 얻는다. 전직 광부는 완력 +1, 산전수전 다 겪은 사람은 냉정 +1, 무당의 손녀는 직감 +1을 받으며, 박씨와 구면은 수치 보너스 대신 그와 얽힌 전용 스토리와 히든 선택지를 얻는다.
- **능력치 배분**: 완력(금) · 냉정(관계) · 직감(안전) 세 스탯에 포인트를 배분한다. 스탯마다 지키는 대상이 다르다. 배경 보너스는 배분과 별개로 더해진다.
- **핵심 루프**: 1갱부터 5갱까지, 매 갱에서 조사(안전) / 캔다(금 획득, 위험 동반) / 돌아간다(즉시 탈출) 중 선택한다.
- **주사위 판정**: d20 + 스탯으로 완력·냉정·직감 판정을 한다. 갱이 깊어질수록 난이도가 오른다. TRPG가 낯선 플레이어를 위해 DC 옆에 대략적인 성공 확률(%)을 함께 표시한다.
- **선택지 이모지**: 주사위 판정이 필요한 선택지는 🎲, 안전한 선택은 🛡️/🔍, 판정 없이 성공하는 히든 선택지는 ✨ 등 선택지 성격에 맞는 이모지가 붙는다.
- **타락 게이지**: 캘 때마다 차오른다. 3부터 기척이, 6부터 위험한 선택지가, 9부터 강제 사건이 열리고 10에서 다크 엔딩이 확정된다.
- **동행 박씨**: 탐욕스러운 선택을 할 때마다 그와의 관계가 위태로워진다. 냉정으로 관계를 회복하거나(또는 박씨와 구면이라면 판정 없이 성공하는 화해 히든 선택지로), 끝내 그를 버릴 수도 있다. 관계가 완전히 무너지면 박씨가 금 일부를 챙겨 배신하고, 끝까지 함께하면 탈출 시 그가 몫을 나눠준다.
- **배경별 전용 이벤트**: 전직 광부는 전문 지식으로 위험 없이 금을 얻는 히든 선택지를, 무당의 손녀는 갱도 곳곳에서 조상신의 경고를 듣고 할머니의 인도로 금을 찾는 히든 선택지를 한 번씩 쓸 수 있다.
- **엔딩 5종**: 빈손 생환 / 적당히 챙김 / 만선 / 삼켜짐 / 배신자 — 최종 소지금과 타락 수준, 선택에 따라 갈린다.
- **결말 체크리스트**: 시작 화면에서 다섯 결말 중 무엇을 확인했고 무엇이 남았는지 목록으로 보여주며, 아직 못 본 결말에는 도달 조건 힌트가 함께 표시된다.
- **진상 — 제3갱은 몇 번째인가**: 다섯 결말을 모두 확인하면 시작 화면에 숨겨진 에필로그가 열린다. 매번 다른 밤을 보냈다고 믿었던 이야기가, 사실은 어떻게 반복되고 있었는지를 보여준다.

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음, 파일 하나로 동작)
- 폰트: Google Fonts (Black Han Sans, Gowun Batang, IBM Plex Mono)
- 주사위 판정과 일부 사건은 매 판 무작위로 배치되어 재플레이 시 다른 전개가 나온다
- 최고 기록(생환 시 소지금)과 확인한 결말 목록은 `localStorage`에 저장되어 시작 화면에 표시된다
